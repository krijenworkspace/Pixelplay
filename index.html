Fullscreen mode

Keyboard + touch

Desktop controls and on-screen mobile buttons are included in supported games.

🏆
Best scores

Scores are tracked during the current session. Persistent leaderboards can be added with a backend later.

Project note: PixelPlay is an original starter arcade, not a copy of Subway Surfers, Temple Run, Hill Climb Racing or a commercial racing game. The runner and driving games are lightweight original prototypes. 3D modes load Three.js from a CDN and require an internet connection. Shared online multiplayer and global leaderboards need a separate realtime backend; GitHub Pages alone only hosts static files.
